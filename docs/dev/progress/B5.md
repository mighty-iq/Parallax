## Decisions
- Hole Punch reuses Fold's exact model on a 4 × 4 sheet through the export block at the end of
  js/ex/fold/gen.js: `lib.sheet(4, fn, hooks)` runs Fold's own attempt/check with the sheet size 4
  for one synchronous call (restored in a finally); hooks widen the foil pool, replace the foil
  selection and set 5 options. Fold's own items are unchanged (node test compares with a context
  without patfold; Fold's own node test passes).
- Hole Punch: 2–3 folds only (official rule "multiple folds"; with one fold the hole-under-the-punch
  and symmetry rules cannot both be matched), 5 options (prep sources say 4 or 5), range 2.7 logits
  (< 4: format capped at 3 folds, 1 punch). Declares requires: ['fold'].
- Angles: own deterministic sincos/atan2; gap levels 6/5/4/3/2° (floor 2° everywhere: the generator
  cannot see the screen; 8° dropped because tip distance/area follow the angle at wide spans); arms
  0.3–1·L chosen against tip-distance/area/arm-length cues (weights 2.5/1.5/1); κ 1.3–1.6; ranges
  right 70–110, acute 25–72, obtuse 108–155; resolve levels extremes/middle/closest.
  practice: 'perception' (B7 shows the tag in the Library; play.js label request open).
- Painted Cubes: own model + software z-buffer; camera az 31°, el 33.5° (lattice separation 0.35);
  dims cubes / tallest column / asked N; no "hidden" dim (a figure with every top in view hides only
  supports; "none hidden" is unreachable above ~10 cubes); N = 5 never asked; key balanced per N via
  KRANGE; extraParams ask for Section mode.
