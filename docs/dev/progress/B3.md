## Decisions (for the lead's DECISIONS.md)
- Homing version bump 1 → 2: seeds now give different items (speed, legs), so old rows must not mix with new ones.
- Reckon keeps the player's own error history in a store field 'reckon' (registered from reckon/view.js) for the bias line.
- Kit captions are subtitles over the view (lead's brief), not .ex-caption; fit.py's Watch check needs the selector.
- Void rule judged by harm: freeze > 1 s while moving, slow frames (> 100 ms) over half the moving time, lost
  context, view shape change, pause; never in fast mode.
- Answer buttons act on a finger's pointerup (kit.tapAct), not on the browser's click.
