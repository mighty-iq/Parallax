## Decisions (for the lead's DECISIONS.md)
- Record format v2 (store VERSION 2): protects v1.1 data from a 1.0 tab (it runs from memory instead of stripping fields).
- Time box ends on a closing item one item (session pace) before the budget, or right after an item that ran past it.
- Daily on the local date; the scored attempt is spent only when all items are answered (partial attempts resume).
- Threshold: stopped runs are not saved at all (reported only). Speed achievement needs a full-time session.
- An answer and moving to the next item count as clock activity (so API-driven tests and real players alike never
  trip the idle cap mid-flow); idle = 60 s without any input event.
- Daily pool excludes PAT formats always (same for everyone), never filtered by personal settings.
